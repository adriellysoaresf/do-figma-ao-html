# ✦ Do Figma ao HTML

### Do design para o código.ᐟ

Projeto desenvolvido para praticar a transformação de uma interface criada no **Figma** em uma página web utilizando **HTML e CSS**.

## ✦ Sobre o projeto

Este projeto foi desenvolvido durante meus estudos de Front-end com o objetivo de entender, na prática, como transformar um layout visual em código.

A interface trabalha uma identidade inspirada em uma alcateia, com hero section, navegação, chamada para ação e rodapé.

## ✦ O que pratiquei

- Estrutura semântica com HTML
- Separação entre HTML e CSS
- Header, navegação, main, section e footer
- Flexbox
- Espaçamentos e alinhamentos
- Cores e tipografia
- Organização e inserção de imagens
- Favicon
- Transformação de um layout do Figma em código
